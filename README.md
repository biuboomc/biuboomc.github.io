# Guanxu Chen

Personal academic website for Guanxu Chen, built with HugoBlox Academic CV and deployed with GitHub Pages.

## Local development

Install Hugo Extended and pnpm, then run:

```bash
pnpm install
pnpm run dev
```

Build the site:

```bash
pnpm run build
```

## Content

- English homepage: `content/_index.md`
- Chinese homepage: `content/zh/_index.md`
- Profile data: `data/authors/me.yaml`
- Publications: `content/publications/` and `content/zh/publications/`
- Projects: `content/projects/` and `content/zh/projects/`
- CV PDF: `static/uploads/cv.pdf`
